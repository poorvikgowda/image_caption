## 🚀 Quick Commands (Run in this order)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Prepare dataset (auto-generates synthetic if Flickr8k not present)
python scripts/prepare_data.py

# 3. EDA
python scripts/eda.py

# 4. Train (use --epochs N for more training)
python scripts/train.py --epochs 20

# 5. Evaluate on test set
python scripts/evaluate.py --checkpoint checkpoints/best_model.pth

# 6. Generate a caption for any image
python scripts/inference.py --image path/to/image.jpg --method beam --beam-size 3

# 7. Launch Streamlit web app
streamlit run app/app.py

# 8. Launch FastAPI REST API
uvicorn app.api:app --reload --port 8000

# 9. Run unit tests
python -m pytest -v tests/
```

## ⚠️ Known Limitations

- **Synthetic dataset**: Low vocab (~68 words) and limited diversity. Model shows basic grammatical
  structure but not semantic quality. Real BLEU scores require actual Flickr8k training.
- **CPU only**: Full training on real Flickr8k (8091 images × 20 epochs) will take several hours on CPU.
  A CUDA GPU reduces this to ~30-60 minutes.
- **Streamlit attention heatmaps**: Require opencv-python installed; works cleanly.
- **Transformer decoder**: Has a minor attention mask deprecation warning in PyTorch 2.14+ (non-blocking).

## 🎯 Architecture Summary

```
Image → ResNet-50 (7×7×2048) → Bahdanau Attention (49 regions) → LSTM Decoder → Caption
```

- **Encoder**: Pretrained ResNet-50, frozen during initial training
- **Attention**: Bahdanau additive attention (encoder_dim=2048, attention_dim=256)
- **Decoder**: Single-layer LSTM with gated context vector (hidden_size=512)
- **Training**: AdamW, encoder_lr=1e-4, decoder_lr=4e-4, gradient_clip=5.0
- **Inference**: Beam Search (k=3) with length normalization penalty α=0.7
- **Metrics**: BLEU-1..4, ROUGE-L, METEOR, CIDEr
