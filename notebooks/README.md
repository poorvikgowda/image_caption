# Jupyter Notebooks Overview

This directory contains analytical and visualization workflows for the Image Caption Generation project:

1. `01_eda.ipynb`: Interactive Exploratory Data Analysis (Dataset statistics, sentence length distributions, top word frequency histograms). Alternatively run `python scripts/eda.py`.
2. `02_training_analysis.ipynb`: Training dynamics inspection (Loss curves, learning rate decay, teacher forcing ratio progression).
3. `03_results.ipynb`: Quantitative evaluation matrix, attention heatmap rendering, qualitative visual comparison grids.
